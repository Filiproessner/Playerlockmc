# Fabric Example Aim Mod (Minecraft 1.21.1)

A small Fabric mod for Minecraft 1.21.1 that automatically aims at the nearest player and allows adjustable smoothness and range.

## Features

- **Auto-Aim:** Hold the `R` key to automatically rotate your character toward the nearest player.
- **Adjustable Range & Smoothness:** Use the in-game GUI (`G`) to change the aiming range and rotation speed.
- **GUI Controls:** Sliders for Range (1–50 blocks) and Smoothness (0.05–1.0).

## Installation

1. Install Minecraft 1.21.1 with Fabric Loader.
2. Install the Fabric API for 1.21.1.
3. Place the mod `.jar` file into your `mods` folder.
4. Launch Minecraft.

## Usage

- **Hold R** → Auto-Aim is active.
- **Press G** → Open the GUI to adjust Range and Smoothness.
- **Close** button → Close the GUI.
